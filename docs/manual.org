#+AUTHOR: Avikalpa Kundu
#+OPTIONS: toc:2 num:t

* Introduction

ymacs is a GNU Emacs fork on libyggterm written in Common Lisp (SBCL/ECL).
It delivers modern Emacs with sane defaults, true concurrency, and deep
ytrace observability, targeting ~90% ELPA/MELPA plug-and-play via modern
helpers (vertico/consult/corfu) and discarding duplicate old interfaces
(ido/helm/ivy/company/linum).

This manual is the literate book for ymacs — every chapter is prose plus
executable Lisp blocks tangled via init.org.

* Chapter 1: Installation and Startup

** Requirements

- SBCL 2.6+ or ECL 24.5+ (SBCL primary, ECL fallback)
- yggterm 3.2+ (for libyggterm surfaces)
- ytrace (optional, for probes)

** Building

#+begin_src sh
sbcl --load build.lisp
./install.sh
ymacs --version  # 0.1.1, 6-8ms startup
#+end_src

** Fleet Install

#+begin_src sh
scp ymacs-bin jojo:~/.local/bin/ymacs-bin
scp bin/ymacs jojo:~/.local/bin/ymacs
ssh jojo "~/.local/bin/ymacs --help"
#+end_src

** First Run

#+begin_src lisp
(ymacs:start)  ; 4-8ms, control at http://127.0.0.1:xxxxx
#+end_src

* Chapter 2: Buffers and Windows

ymacs buffers are rope-backed (piecewise rope, 4k chunks) with value_key
stability for concurrent edits. The single-sidebar rule (max 1 pane) keeps
focus; tiles are optional for split views.

** Buffer API

- (make-new-buffer "*scratch*" "hello")
- (open-file-buffer "/home/user/notes.org")
- (buffer-insert buf pos text)
- (buffer-delete buf pos len)
- (buffer-save buf)
- (kill-buffer id)

** Window Management

- (make-tile buffer) — create tiled window
- (split-tile-horizontally tile)
- (balance-tiles)

* Chapter 3: Keymaps and Which-Key

Global map + local maps per major mode. which-key shows pending prefixes
in the Which Key rail pane.

** Default Bindings

| Key       | Command               |
|-----------|-----------------------|
| C-x C-f   | find-file (vertico)   |
| C-x C-s   | save-buffer           |
| C-x b     | consult-buffer        |
| C-s       | isearch-forward       |
| M-x       | execute-extended-command |
| C-g       | keyboard-quit         |
| C-/       | undo                  |
| C-y       | yank                  |

** Which-Key

#+begin_src lisp
(which-key-enable t)
(which-key-register-prefix "C-x" '(("C-f" . "find file")))
#+end_src

* Chapter 4: Minibuffer and Completion

Minibuffer uses vertico + consult + orderless + marginalia for modern
completion. consult-buffer, consult-find, vertico-mode.

* Chapter 5: Search and Replace

- isearch-forward/backward with regexp and case-fold
- query-replace
- consult-line, consult-ripgrep (via ytrace)

* Chapter 6: Major Modes

** Fundamental, Lisp, Org, Python, C, Dired, Eshell

Each mode defines keymap, syntax, hook. Auto-set via file extension.

** Org Mode

Headings, TODO, agenda, babel tangle.

#+begin_src lisp
(org-todo buf)
(org-agenda)
(org-babel-tangle)
#+end_src

** Lisp Mode

REPL, slime-like eval, paren matching.

* Chapter 7: Package Management

Only =use-package= is blessed. Modern helpers are vertico/consult/corfu;
old duplicates (ido/helm/ivy/company/linum) are discarded with diagnostic.

#+begin_src lisp
(ymacs-use-package vertico :ensure t :init (vertico-mode 1))
(ymacs-use-package which-key :ensure t :config (which-key-mode 1))
#+end_src

* Chapter 8: Daemon and Surfaces

Two-tier daemon/client (emacsclient model). Control via OSC 7717
declare/heartbeat/close and TcpListener 127.0.0.1:0 with GET /ping,
/pane/doc etc. Endpoint-ping liveness.

* Chapter 9: Ytrace Probes

In-process probes: startup, buffer-mutation, redisplay, sidebar, elpa,
control, which-key, use-package, tile, fold, mc, session.

* Chapter 10: Literate init.org

Default config is init.org book with prose + (tangle) blocks.
